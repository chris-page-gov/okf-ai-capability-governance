What changes if the agent sends its own reply

The baseline. The agent sorts correspondence into queues and drafts a suggested reply from approved templates. A caseworker commits the action, so nothing leaves the organisation without a named person attached. The baseline sits at Tier 3 · Enhanced.
The send variant. The publisher’s wording is that one word in the mandate, “send” rather than “draft”, creates an effect that no later correction undoes. The example moves to Tier 4 · Critical.
Autonomy stays capped. The cap remains L1 · Draft only, so a person still edits and commits every output. The publisher says autonomy is forced to draft-only whatever the tier. Read plainly, the example refuses the change. It does not describe a safe way to hand over sending.
Shadow mode becomes mandatory. The pilot suggests running the agent beside human handling with sending switched off, and keeping evidence of how the draft-only boundary and escalation worked. These are described as illustrative test ideas.
Reassessment. The playbook calls for a fresh assessment whenever new actions are added. The evidence brief asks for the changed mandate, the shadow-mode results, unresolved issues and a named local reviewer’s decision.
Excluded correspondence. The baseline already keeps complaints, legal threats, safeguarding concerns and data-subject requests away from the agent. They go to a human unopened.
