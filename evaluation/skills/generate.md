name: okf-pilot-generate
description: Draft a portable OKF 0.3 concept or proposed OKF+ change from supplied public evidence, including provenance and proposed validation. Use for authoring the correspondence pilot.
---

Start with the supplied bundle index, core version, declared profile and authored source. Preserve exact identifiers and source facts. Propose changes to the declared authored inputs. Do not change generated projections, the user's files, third-party sites or release settings. Where asked for an example concept, make it a labelled draft, include source references and add explicit uncertainties.

Record claimed authority, scope, status and documentary evidence for each proposed relationship. Preserve publisher attribution and document unresolved evidence and local decision rights. State which checks were actually run. For a change proposal, list appropriate OKF 0.3 core, graph parity, source locator and build checks, and request explicit validation evidence before describing a bundle as verified or published. Never claim to have run the Codex guarded launcher or semantic reconciler in a different client.
