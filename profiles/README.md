# Correspondence pilot profile v1

This pilot declares OKF core 0.3 and a local semantic sidecar,
`urn:okf:ai-capability-governance:profile:v1`. Its authored relationships carry
their predicate, direction, case scope, publisher link, witness and licence.
Both graph serialisations derive from the same records.

`semantic-assertion.schema.json` is the unchanged evidence assertion schema
from Explorer’s frozen Bundle Wiki v1 profile. Reusing its assertion shape does
not adopt the Bundle Wiki v1 profile, which targets OKF 0.2. The installed
Explorer reconciler requires 0.2. This pilot applies graph and assertion checks
directly and uses the guarded OKF skill launcher for core checks.
